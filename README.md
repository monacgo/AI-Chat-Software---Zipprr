## 🛠 Installation
<sub>[↑ Back to top](https://zipprr.com/ai-chat/)</sub>

<sub>After installation, configure your [Environment Variables](https://zipprr.com/ai-chat/) and review the [Folder Structure](https://zipprr.com/ai-chat/) below.</sub>

### ✅ Requirements

| Requirement | Minimum Version |
|---|---|
| PHP | 8.2+ |
| Composer | 2.x |
| MySQL / MariaDB | 8.0 / 10.4+ |
| Node.js | 18.x+ |
| Redis | 6.x+ (recommended) |

### 📦 Step-by-step Setup

```bash
# 1. Clone the repository
git clone https://github.com/zipprr/ai-chat-software.git
cd ai-chat-software

# 2. Install PHP dependencies
composer install --optimize-autoloader --no-dev

# 3. Install Node dependencies
npm install

# 4. Configure environment
cp .env.example .env
php artisan key:generate

# 5. Run database migrations
php artisan migrate --seed

# 6. Link storage
php artisan storage:link

# 7. Build frontend assets
npm run build

# 8. Start the queue worker
php artisan queue:work

# 9. Run the application
php artisan serve
```

<div align="center">

> 💡 **Tip:** For production, use Supervisor to keep `queue:work` running persistently, and configure a proper web server (Nginx/Apache) instead of `artisan serve`.

</div>
